How it behaves

  • It shows only on a unit page opened from My Lessons. The chapter organization page and the My Classes view stay as they are.
  • It lists every class that has this chapter attached, including one that hasn't started it. A class that has finished the chapter is left out. If no class has it attached, the row doesn't appear and the title stays where it is.
  • Tapping a class opens that class's own lesson (bookmark, Mark complete) on its current unit, the same as tapping its card in My Classes.
  • The class name is her own name for it if she gave one (for example "Rose"), otherwise 6A. Classes are listed in the order of her teaching profile.
  • Capsules use the kicker's type size (10.5px mono) and wrap to a second line if there are many. The unit title moves down one row.
