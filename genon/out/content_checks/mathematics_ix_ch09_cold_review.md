## Summary

35 findings: **0 S1, 6 S2, 29 S3**. Of the S3s, 3 are register rows (27–29), 1 is a coverage note (35), and the rest are minor.

I found no wrong truth value, no "converse" that is really something else, no bogus counterexample, and no wrong MCQ key in any file. Every book reference matches the PDF.

The six S2s, in order:
- **Row 1:** Q17(ii)(a) in canonical Unit 15 answers "must the sticks be equal?" with "Yes", stating necessity where the property only gives sufficiency. This is borderline S1.
- **Row 2:** p13 Unit 7 records a false general rule, "coprime divisors ⇒ converse holds".
- **Row 3:** p13 Unit 10's time band and teacher note disagree on the first failure of n²+n+11 (n = 11 vs n = 10; n = 10 is right).
- **Row 4:** p13 Unit 10 has leftover self-correcting working for Q14(ii).
- **Row 5:** canonical defers the "both false" case and never gives a model, yet later asks students to place chapter examples in that category.
- **Row 6:** p13 Unit 12 tells students to pick exercises "not yet completed or reviewed" when all four were.

**Could not verify / unsure:**
- (a) Whether Q13 intends n ≥ 0 or n ≥ 1. The book does not say; this affects p10 Unit 8 (row 8).
- (b) Whether the book's intended Q17(ii)(a) answer is "yes, use equal sticks (to guarantee)" or "not necessarily". That decides whether row 1 is S1 or S2.
- (c) The Q3 converse analysis (row 35) is my own derivation, not in the book: IE = r/sin(β+2γ) and IF = r/sin(γ+2β), so IE = IF ⇔ B = C or A = 60°. I checked it numerically: a triangle with A = 60°, B = 80°, C = 40° gives IE = IF ≈ 0.2578 although AB ≠ AC.
